\section{Materiales y métodos}

Este estudio se desarrolló mediante un pipeline computacional reproducible basado en análisis de redes y anotación funcional. Todos los análisis se ejecutaron en \textbf{Python 3.10} \cite{Python_2023} (bibliotecas \texttt{pandas} \cite{McKinney2010_pandas} y \texttt{requests}) y \textbf{R 4.3.2} \cite{R_core_2023}, empleando los paquetes \texttt{igraph} (v1.5.1) \cite{Csardi2006_igraph}, \texttt{clusterProfiler} (v4.10.1) \cite{Yu2012_clusterProfiler} y \texttt{org.Hs.eg.db} (Bioconductor) \cite{bioc_manual}. Las interacciones proteína–proteína se recuperaron mediante la API de \textbf{STRING v12.0} \cite{Szklarczyk2019_STRING} y la visualización opcional se realizó con \textbf{Cytoscape v3.10.1} \cite{Shannon2003_cytoscape}. Todas las salidas se almacenaron en \texttt{results/}, acompañadas de ficheros \texttt{.meta.json} para documentar parámetros clave y trazabilidad temporal.

\subsection{Obtención, normalización y anotación de genes}

Los genes asociados al fenotipo \textit{Abnormal drinking behaviour} (HP:0030082) se obtuvieron a partir del fichero oficial \texttt{phenotype\_to\_genes.txt} proporcionado por la \textbf{Human Phenotype Ontology} (HPO) \cite{robinson2008hpo, kohler2021hpo}. Este archivo contiene asociaciones fenotipo–gen \textit{inferidas} mediante la estructura jerárquica de la ontología. El script \texttt{01\_download\_hpo\_genes.py} descarga dicho fichero desde el repositorio de HPO, filtra por el identificador de interés mediante el paquete \texttt{org.Hs.eg.db} (R 4.3.2) y genera los archivos \texttt{hpo\_genes.csv} y \texttt{hpo\_genes.meta.json}.

La estandarización se realizó con \texttt{02\_clean\_genes.R}. Se eliminaron duplicados y se mapearon los símbolos génicos a identificadores \textbf{ENTREZ} y \textbf{ENSEMBL} mediante el paquete \texttt{org.Hs.eg.db} \cite{bioc_manual}. Los genes sin correspondencia oficial se registraron en \texttt{genes\_no\_reconocidos.txt}. El conjunto normalizado final se almacenó en \texttt{clean\_genes.csv} para su uso en fases posteriores.

\subsection{Interacciones PPI y construcción de la red inducida}

Las interacciones proteína–proteína se obtuvieron a través de la \textbf{API REST de STRING} \cite{Szklarczyk2019_STRING}, utilizando una consulta por lotes para la especie \textit{Homo sapiens} (taxid 9606). El script \texttt{03\_string\_interactions.py} filtró las interacciones con un umbral de alta confianza equivalente a \textit{score} $\geq 0.7$ (escala 0--1). Para construir una \textbf{red inducida} por los genes del fenotipo, se conservaron solo los pares en los que ambos genes pertenecen al conjunto HPO depurado. Las aristas A--B y B--A se consolidaron reteniendo el \textit{score} máximo. El resultado se guardó como \texttt{string\_edges.csv}, incluyendo la evidencia asociada (p.\,ej., \textit{experimental}, \textit{database}, \textit{textmining}).

La construcción del grafo se realizó con \texttt{04\_build\_network.R} empleando \texttt{igraph} \cite{Csardi2006_igraph}. El grafo se definió como no dirigido y ponderado, usando el \textit{score} de STRING como peso de arista. Se eliminaron nodos aislados y se calcularon métricas de centralidad (grado, \textit{betweenness}, \textit{closeness}) y coeficiente de agrupamiento local mediante \texttt{transitivity()}. La identificación de módulos se realizó con el algoritmo de \textit{Louvain clustering} \cite{Blondel2008_Louvain}. El grafo final se almacenó como \texttt{network\_graph.rds} y las métricas en \texttt{network\_metrics.csv} y \texttt{network\_summary.csv}.

Adicionalmente, se integró información farmacológica mediante consultas a \textbf{ChEMBL} \cite{gaulton2012chembl} (incluido en el script de STRING), generando \texttt{chembl\_targets.csv}. Esta información se añadió como atributo binario a los nodos (\texttt{is\_chembl\_target}).

\subsection{Enriquecimiento funcional y visualización de resultados}

El análisis funcional se realizó con \texttt{05\_enrichment\_analysis.R}, utilizando \texttt{clusterProfiler} \cite{Yu2012_clusterProfiler} para ejecutar enriquecimiento GO: Biological Process \cite{Ashburner2000_GO} y KEGG \cite{Kanehisa2000_KEGG}. Se seleccionaron los \textbf{20 genes con mayor betweenness} como subconjunto prioritario. Se aplicó corrección por FDR mediante Benjamini--Hochberg, reteniendo términos con \(p_{\mathrm{aj}}<0.05\). Los resultados se guardaron en \texttt{enrichment\_GO.csv} y se generó una figura tipo \textit{dotplot} mediante \texttt{enrichplot}.

La generación de figuras finales se realizó mediante \texttt{06\_export\_figures.R}, produciendo: (i) un histograma de grado, (ii) una visualización de módulos en la red y (iii) un heatmap de los principales hubs. Las figuras se almacenaron en \texttt{RESULTS/figures/}. Para visualización interactiva adicional se utilizó \textbf{Cytoscape} \cite{Shannon2003_cytoscape} empleando un diseño \textit{force-directed}.

\subsection{Ejecución del pipeline y reproducibilidad}

La ejecución completa del pipeline se realizó secuencialmente desde \texttt{CODE/scripts/}, siguiendo el orden:

\begin{verbatim}
python 01_download_hpo_genes.py
Rscript 02_clean_genes.R
python 03_string_interactions.py
Rscript 04_build_network.R
Rscript 05_enrichment_analysis.R
Rscript 06_export_figures.R
\end{verbatim}

Cada script emplea rutas relativas y genera un fichero de metadatos.
